Kurenai

A free CleanClip alternative

I used CleanClip every day for years. After a macOS update it kept crashing, and the paste queue I relied on was behind the paid version anyway. So I wrote Kurenai, and I kept the shortcuts I was used to.

What carries over

  • ⌘; opens the history, ⌘1 to ⌘9 paste an item straight away.
  • ⌘I opens your saved lists, a digit pastes a line.
  • ⌘' is the paste queue: copy a few things, then each ⌘V pastes the next one. ⇧⌘C splits a selected column into lines. It's free here.

Every shortcut can be changed in Settings if you had your own.

What's different

  • It's open source, so you can see exactly what it does with your clipboard.
  • Passwords from password managers are never saved, and the history file is encrypted.
  • No account, no subscription, nothing sent anywhere.
  • Text and images only for now. Files copied in Finder aren't kept.

Moving over

Quit CleanClip, install Kurenai, allow Accessibility when it asks. Your old CleanClip history doesn't come along, Kurenai starts fresh.
