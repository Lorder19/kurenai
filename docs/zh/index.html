      按行拆分

      选中一列按 ⇧⌘C，Kurenai 会把它切成多行放进队列，适合把表格里的一列填进网页表单。

      隐私

      你的数据只属于你

      • 从密码管理器（1Password、Bitwarden、Apple 密码等会标记为机密的应用）复制的密码永远不会被保存。
      • 你可以选择忽略哪些应用。“钥匙串访问”和“密码”默认就在列表里。
      • 历史和图片在磁盘上加密存储。说实话：密钥就放在旁边，你的账户可以读取，所以它防的是文件泄露，而不是坐在你 Mac 前的人。
      • Kurenai 的窗口被标记为私密：macOS 截图会跳过它们，在 Telegram 共享屏幕时也看不到。少数录屏工具会忽略这个标记，介意的话请自己确认一下。
      • 没有账号，没有统计。唯一的网络请求是检查更新，默认关闭。
      安装

      一分钟就能用上

      用 Homebrew:
      brew install --cask lorder19/tap/kurenai
      或者手动安装:
      1. 下载 Kurenai.zip，解压后把 Kurenai 拖进“应用程序”。
      2. 打开它。macOS 会提示开发者身份不明，因为我还没付钱给 Apple 买证书。打开“系统设置 → 隐私与安全性”，点击“仍要打开”。
      3. 按提示允许“辅助功能”权限。Kurenai 只用它来替你按 ⌘V。

      常见问题

      为什么不直接用 macOS Tahoe 自带的剪贴板历史？

      它适合找回复制过的东西。Kurenai 则是为粘贴设计的：编号条目、常用列表和粘贴队列，全部用键盘操作。

      快捷键有时没反应

      当密码输入框处于焦点时，macOS 会开启安全输入，阻止所有应用的全局快捷键。有些密码管理器忘了关闭它。切换应用或重启密码管理器即可解决。出现这种情况时 Kurenai 会在菜单里提示。

      在菜单栏找不到图标

      在带刘海的 MacBook 上，多余的图标会被挡住。快捷键照常可用，从聚焦搜索再次打开 Kurenai 会弹出设置。

      怎么卸载？

      退出 Kurenai，删除应用，再删除 ~/Library/Application Support/Kurenai 文件夹。

      会一直免费吗？

      是的，这里介绍的功能会一直免费。以后可能会推出付费版，加入保留格式粘贴等功能，用来支付 Apple 开发者账号的费用。
